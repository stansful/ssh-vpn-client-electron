# Shadow

**Русский** · [English](README.en.md)

> **Дисклеймер.** Это приложение — проверка того, могут ли современные нейросети создавать приложения
> с минимальным участием разработчика. Ответ — **да**.

Shadow — десктопный клиент, который пускает трафик через ваш собственный сервер: по SSH или через Xray
(VLESS, VMess, Trojan, Hysteria 2). Работает на Windows, macOS и Linux.

![Экран подключения: туннель SSH активен](docs/images/connect.png)

## Что умеет

- **Два способа подключения.** SSH-туннель на любой сервер, куда вы заходите по SSH: на сервер ничего ставить не
  нужно. Или Xray-профиль из ссылки `vless://`, `vmess://`, `trojan://`, `hysteria2://`.
- **Раздельный туннель.** Через сервер идут только выбранные сайты, IP-адреса и приложения, остальное — напрямую.
  Можно и наоборот: весь трафик через туннель.
- **Готовые списки сайтов.** Список «заблокировано в России» подключается одним переключателем вместо сотни правил.
- **Сам переподключается.** Если связь оборвалась после сна ноутбука, смены Wi-Fi или сбоя сервера, Shadow
  восстановит туннель без вашего участия.
- **Хранит секреты надёжно.** Пароли, ключи и ссылки шифруются системным хранилищем (Windows DPAPI, macOS Keychain,
  Linux keyring) и не попадают в журналы.
- **Живёт в трее.** Закрытое окно не рвёт туннель; на Windows Shadow может стартовать вместе с системой.

Интерфейс приложения — на английском.

## Как это выглядит

### Подключение

Одна большая кнопка. Сверху выбирается транспорт — SSH или Xray. Рядом сводка маршрутизации и проверка туннеля:
она отправляет тестовый запрос через сервер и показывает, дошёл ли он и за сколько.

![Подключение через Xray-профиль](docs/images/connect-xray.png)

Для SSH-сервера есть встроенный терминал: можно выполнить команду на сервере, не открывая отдельный клиент.

![Встроенный терминал сервера](docs/images/terminal.png)

### Маршрутизация

Полный туннель или раздельный. В раздельном режиме через сервер идут только домены, IP-адреса, приложения и списки
доменов, которые вы выбрали. Изменения применяются сразу, даже во время подключения. Правила управляют трафиком
на Windows (подробнее — в [таблице ниже](#что-работает-на-какой-системе)).

![Выбор режима и списки доменов](docs/images/routing.png)

Правила для приложений: укажите `telegram.exe` или выберите программу из запущенных, и весь её трафик пойдёт через
туннель. TUN-адаптер ловит даже тех, кто игнорирует системный прокси. Правила можно импортировать и экспортировать.

![Правила для приложений и TUN-адаптер](docs/images/routing-apps.png)

### SSH-серверы и ключи

Вход по паролю или ключу (RSA, Ed25519; форматы OpenSSH и PEM). Отпечаток сервера можно закрепить, чтобы подмена
хоста не прошла незамеченной.

![Список SSH-серверов](docs/images/servers.png)

![SSH-ключи](docs/images/keys.png)

### Xray-профили

Вставьте одну ссылку или сразу много, по одной на строку: повторы не задублируются. Профили можно искать,
закреплять и переименовывать. Публичный список профилей загружается только по кнопке.

![Xray-профили](docs/images/profiles.png)

### Журнал

Важные события — например, TUN-адаптер не включился или туннель закрылся, потому что не осталось правил, —
остаются наверху, пока вы их не закроете.
Ниже — живая лента событий и файл журнала. Пароли и ключи в журнал не попадают.

![Журнал событий](docs/images/activity.png)

### Оформление

Светлая, тёмная или своя тема, акцентные цвета на выбор.

![Настройки оформления в светлой теме](docs/images/appearance-light.png)

## Что работает на какой системе

|                                              | Windows | macOS | Linux |
| -------------------------------------------- | :-----: | :---: | :---: |
| Туннель SSH и Xray                           |   ✅    |  ✅   |  ✅   |
| Локальный прокси HTTP и SOCKS5               |   ✅    |  ✅   |  ✅   |
| Системный прокси включается сам              |   ✅    |   —   |   —   |
| Раздельный туннель: сайты, IP, списки        |   ✅    |   —   |   —   |
| Правила для приложений                       |   ✅    |   —   |   —   |
| TUN-адаптер (запуск от администратора)       |   ✅    |   —   |   —   |
| Иконка в трее или строке меню                |   ✅    |  ✅   |  ✅   |
| Автозапуск при входе в систему               |   ✅    |   —   |   —   |

На macOS и Linux Shadow поднимает локальный прокси на `127.0.0.1`. Его адрес показан на экране Connect: укажите его
в настройках браузера или нужного приложения.

## Установка

Скачайте файл для своей системы со страницы [последнего релиза](https://github.com/stansful/ssh-vpn-client-electron/releases/latest).

| Система             | Файл                                                              |
| ------------------- | ----------------------------------------------------------------- |
| Windows 10/11       | `…-windows-portable-x64.exe` или `…-arm64.exe`, установка не нужна |
| macOS               | `…-macos-dmg-arm64.dmg` (Apple Silicon) или `…-x64.dmg` (Intel)  |
| Linux               | `….AppImage` или пакет `….deb` для x64 и arm64                    |

Сборки не подписаны сертификатами Microsoft и Apple, поэтому при первом запуске система предупредит:

- **Windows:** в окне SmartScreen нажмите «Подробнее» → «Выполнить в любом случае».
- **macOS:** откройте «Системные настройки» → «Конфиденциальность и безопасность» и нажмите «Всё равно открыть».
  Если macOS пишет, что приложение повреждено, выполните `xattr -dr com.apple.quarantine /Applications/Shadow.app`.

Обновления проверяются в «Settings» → «Updates»: Shadow найдёт новую версию на GitHub, скачает и проверит файл,
а установить его нужно вручную.
Обновляетесь с Shadow SSH 2.4.0 или старше — смотрите [заметки о переезде](docs/DEVELOPMENT.md).

## Быстрый старт

1. Добавьте сервер в «SSH servers» или вставьте ссылку в «Xray profiles».
2. В «Routing» выберите режим: весь трафик или только выбранное.
3. Нажмите большую кнопку на экране «Connect».

## Для разработчиков

Нужны Node.js 22.12+ (или 24+) и npm 10+. Для сборки установщиков — ещё Go 1.23+.

```bash
npm install
npm run dev        # приложение в режиме разработки
npm test           # тесты
npm run build:prod # релизные сборки для всех систем в release/
```

Интерфейс можно открыть и просто в браузере, на демо-данных: `npx vite`, затем
`http://localhost:5173/?scenario=connected`. Так сделаны скриншоты выше.

Сборка, упаковка, устройство туннеля и маршрутизации подробно описаны в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
